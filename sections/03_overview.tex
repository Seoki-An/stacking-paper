\section{Overview} \label{sec:overview}

\subsection{Stacking as an Optimization Problem}
Suppose that we are given a target shape $\target \subset \real^3$ and $n$ irregular shaped objects $\object_1(q_1),\object_2(q_2),\cdots,\object_n(q_n) \subset \real^3$ where each $q_i \in \SE(3)$ represents the pose of each object $\object_i$ in the world frame.
The goal is to find optimal placement poses $q_1,\cdots,q_n$ for a set of irregularly shaped objects such that the final configuration approximates the target shape $\target$ while satisfying the stability and non-collision constraints.
This problem can be formulated as an optimization problem:
\begin{gather}
\min_{q_1,\cdots,q_n\in\SE(3)}  \vol\left(\target\backslash \bigcup_{i=1}^n \object_i(q_i)\right)\quad\text{s.t.} \label{eq:problem_definition}\\
c_\text{phys}(\object_1(q_1),\cdots,\object_n(q_n)) = 0 \nonumber
\end{gather}
where $\vol(\cdot)$ is the volume of a 3D shape and $c_\text{phys}(\cdot)$ is a function that evaluates the physical feasibility of the configuration, including stability and non-collision constraints.

\subsection{Shape Representation}
Throughout the paper, we use the union of differentiable support function (DSF) to represent the 3D shapes of the target shape $\target$ and the objects $\object_i$, $i \in \inventory_k$, in the inventory.
Given a compact convex body $\convex \subset \real^3$, the support function $\dsf_\convex :\real^3 \backslash\{0\} \to \real$ is defined as
\begin{equation*}
    \dsf_\convex(x) = \max_{s \in \convex} x\cdot s
\end{equation*}
where $\cdot$ denotes the standard inner product in $\real^3$.
The work of Lee et al. \cite{lee2023uncertain} presented a differentiable version of the support function $\dsf_\convex$ that represents a smooth shape $\convex$.

The function $\dsf_{\convex}(x)$ can be easily extended through rigid-body transformation as follows:
\begin{equation*}
    \dsf_{\bar{\convex}(q)}(x) = \dsf_\convex(R^\top x) + t \cdot x
\end{equation*}
for $q := (R,t) \in \SE(3)$ where $\bar{\convex}(q)=\{Rp + t\mid p \in \convex\}$ denotes a transformed $\convex$ under rigid-body transformation.
Given two DSF represented convex bodies $\convex_1(q_1)$ and $\convex_2(q_2)$ with SE(3) poses $q_1,q_2$, the signed distance $\sd(\convex_1(q_1), \convex_2(q_2))$ between the two convex bodies can be easily computed using Riemannian optimization techniques associated with $\dsf_{\convex_1(q_1)}$ and $\dsf_{\convex_2(q_2)}$ as presented in An, et al. \cite{an2024riemannianmtd}.
Moreover, due to the smoothness of DSFs, the signed distance $\sd(\convex_1(q_1), \convex_2(q_2))$ and the other contact information (e.g., normal vectors and contact points) are differentiable with respect to $q_1$ and $q_2$, which allows us to use gradient-based optimization techniques.

\subsection{Markov Decision Process Formulation}

Nevertheless, solving the optimization problem in Eq. \eqref{eq:problem_definition} is extremely challenging due to the high-dimensional search space as the number of the objects $n$ increases and the presence of complex physical constraints that involve non-convex and non-differentiable functions.

To address the problem Eq. \eqref{eq:problem_definition} in a tractable manner, we model the problem as a sequential decision-making process where we place one object at a time.
Suppose that we have already placed $k$ objects in the scene and denote the set of indices of the placed objects as $\placed_k \subset \{1,\cdots,n\}$.
Then, the $k$-th scene $\scene_k:=\{(i,q_i)\mid i \in \placed_k \}$ is the collection of object indices and their corresponding placement poses that have been placed in the scene.
Also, let the $k$-th inventory $\inventory_k := \{1,\cdots, n\} \backslash \placed_k$ be the set of remaining object indices that have not been placed yet.
Given $(\scene_k,\inventory_k, \target)$, we now need to select an index $i_{k+1} \in \inventory_k$ and find the corresponding placement pose $q_{k+1}$ for the object. The resulting scene is subsequently simulated to determine whether it is physically feasible and how well it approximates the target shape $\target$.

The sequential decision-making process can be further modeled as a Markov Decision Process (MDP).
We define the state space $\mathcal{S}$ as the set of states $\state_k := (\scene_k, \inventory_k, \target)$, the action space $\mathcal{A}$ as the set of actions $\action_k := (i_{k+1}, q_{k+1})$ representing the object index $i_{k+1}$ and its placement pose $q_{k+1}$, the transition function $\transition:\mathcal{S}\times\mathcal{A}\to\mathcal{S}$ that maps a state-action pair to the next state, and the reward function $\reward:\mathcal{S}\times\mathcal{A}\to\real$ that evaluates the improvement in approximating the target shape $\target$ while satisfying the physical constraints.

More specifically, the pose $q_{k+1}$ in an action is first inserted into the current scene to form a provisional scene $\tilde{\scene}_{k+1} := \scene_k \cup \{ (i_{k+1},q_{k+1}) \}$.
Then, the transition operator evaluates the physical simulation of the provisional scene under gravity and contact dynamics and returns a settled scene $\scene_{k+1}$. 
Therefore, the transition function $\transition$ can be defined as
\begin{equation*}
    \state_{k+1} = \transition(\state_k, \action_k) = (\scene_{k+1}, \inventory_{k+1}, \target)
\end{equation*}
where $\inventory_{k+1} = \inventory_k \backslash \{i_{k+1}\}$.
The implementation of this transition and the reward design are described in Sec. \ref{sec:sequence_planning}.
Therefore, the MDP can be defined as a tuple:
\begin{equation*}
    \mdp = (\mathcal{S}, \mathcal{A}, \transition, \reward, \gamma)
\end{equation*}
where $\gamma \in [0,1]$ is the discount factor that determines the importance of future rewards.

\subsection{Overall Structure of the Sequence Planner}
The overall structure of the sequence planner is illustrated in Fig. \ref{fig:overview}. 
The sequence planner uses Monte Carlo Tree Search (MCTS) to explore the space of possible stacking sequences. For each expansion, it first uses the initial pose sampler $\initpose$ to generate a candidate pose $\hat{q}_{k+1}$, and then uses the pose optimization module $\poseopt$ to refine it into a locally optimal pose $q_{k+1}$. The structural simulation module $\simul$ subsequently implements the physical transition by evaluating the entire provisional scene and producing the settled next state. The resulting validity and simulation statistics are used to determine whether the action is admitted to the search tree and to evaluate its reward.

This gives the following execution flow:
\begin{equation*}
\state_k
\xrightarrow{\ \initpose\ }
\hat{q}_{k+1}
\xrightarrow{\ \poseopt\ }
q_{k+1}
\xrightarrow{\ \simul\ }
\state_{k+1},\ \reward(\state_k,\action_k).
\end{equation*}
We describe pose optimization in Sec. \ref{sec:pose_optimization} and sequence planning, including structural simulation and reward design, in Sec. \ref{sec:sequence_planning}.
