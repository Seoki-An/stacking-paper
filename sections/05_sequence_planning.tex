\section{Sequence Planning} \label{sec:sequence_planning}

\subsection{Initial Pose Sampling}
The sampler $\initpose$ uses volume-biased object sampling with a finite orientation set per object. It favors lower placements and seeds empty scenes near feasible target corners. For object $i$, orientation $R$, and feasible planar location $\planar$, the score (Fig.~\ref{fig:score_map}) is
\begin{equation*}
  \score(\planar\mid i,R)
  =w_\text{s}\score_\text{s}+w_\text{f}\score_\text{f}
   +w_\text{b}\score_\text{b}-w_\text{h}\score_\text{h}-w_\text{d}\score_\text{d},
\end{equation*}
with positive weights. The first four terms measure the fraction of bottom samples near predicted contact, unfilled layer area beneath the footprint, proximity to the feasible placement boundary, and normalized mean contact height, respectively.
A bounded penalty $\score_\text{d}$ on the planar footprint gap to the preceding object (zero for the first placement) encourages nearby placements, helping MCTS assess their interactions without excluding distant proposals.
Inspired by Menezes et al.~\cite{menezes2021rocks}, the floor and boundary terms encourage filling empty layer regions and building inward from the boundary.

We combine elite selection with sampling without replacement weighted by $\exp(\score/\tau)$, $\tau>0$. Proposals start above the scene with clearance and undergo $\poseopt$ refinement, including XY/yaw mutations at the root. Heuristic filters limit planar displacement from each initial pose after optimization and settling, and screen out candidates whose bottoms lie too far above the current construction level or whose equilibrium residual is too large (defined below).

% using the convex XY footprint gap and L = cube root of mean inventory volume.
% XY displacement limit: eta * volume(candidate)^(1/3).
% The active layer advances at a prescribed projected-coverage threshold.
% Standard sampler: volume-biased budgets, platform-specific orientation banks,
% soft previous-action distance, elite fraction 0.25, temperature 0.3.
% Active-layer admission is a construction-order filter after pose optimization,

\subsection{Simulation Module}\label{sec:simulation}
The module $\simul$ uses the same simulation procedure at every search depth.
It settles the new object for a fixed duration with existing objects fixed, then resets velocities and simulates the entire structure's response to the added load.
Structural simulation requires a minimum duration and sustained low mass-normalized kinetic energy.
Excessive accumulated motion, invalid contacts, or failure to settle within the time limit rejects the placement.

The accepted settled scene defines the successor $\state'=\transition(\state,\action)$.
Each disturbance trial starts from rest in this scene and applies a horizontal force at the new object's center of mass:
\begin{equation*}
 \mathbf F_j=\alpha m_{i_{k+1}}g\bigl(\cos\theta_j,\;\sin\theta_j,\;0\bigr)^\top,
\end{equation*}
where $\theta_j=2\pi j/n_d$ for $j=0,\ldots,n_d-1$, $\alpha>0$ sets the force relative to object weight, and $g$ is gravitational acceleration.
The force is removed after $\Delta t_f$ to observe recovery; all placed objects remain dynamic throughout.
Every trial must recover within prescribed tolerances without excessive pose excursion.
These trials assess structural robustness without changing $\state'$.
GPU-accelerated subADMM~\cite{ji2025gpu} enables parallel candidate simulation, complementing the parallel pose optimizer for batched MCTS evaluation.

% Force is applied only at the candidate COM, without an applied torque.

\subsection{Reward Design}
For the newly placed object $i=i_{k+1}$, let $q_i'$ be its pose in the settled successor $s'$ returned by $\simul$ (Sec.~\ref{sec:simulation}). We define the target-volume and object-volume ratios
\begin{equation*}
 \rho_\target=\frac{\vol\bigl(\object_i(q_i')\cap\target\bigr)}{\vol(\target)},
 \quad
 \rho_\object=\frac{\vol\bigl(\object_i(q_i')\cap\target\bigr)}{\vol(\object_i)}.
\end{equation*}
Here $\vol(\cdot)$ denotes volume. The $\rho_\target$ term encourages target filling, while $\rho_\object$ discourages placements extending excessively outside the target. Intersection volumes are estimated on a voxel grid. Failed transitions receive $r(\state,\action)=-1$. For feasible transitions, with fixed normalization scales absorbed into positive weights, the reward is
\begin{equation*}
\begin{split}
 r(\state,\action)={}&w_\target\rho_\target+w_\object[\rho_\object-\tfrac12]_+
 -w_E e(\action)\\
 &+w_H\bigl(\phi_H(\state)-\phi_H(\state')\bigr)
 -w_D D,
\end{split}
\end{equation*}
where $[x]_+=\max(x,0)$, so the containment bonus is active above $50\%$. Coverage lost through motion of earlier objects is not subtracted. The height term rewards the decrease in surface-height variance $\phi_H(s)=\langle(H_s-\langle H_s\rangle_\Omega)^2\rangle_\Omega$ between parent and settled successor. Here $H_s$ is height over the target footprint $\Omega$, zero at empty cells, and $\langle\cdot\rangle_\Omega$ denotes the area-weighted mean.

The equilibrium score uses residual forces $\mathbf f_l$ and torques $\boldsymbol\tau_l$ returned by pose optimization:
\begin{equation*}
 e(\action)=\max_l\left(
 \frac{\|\mathbf f_l\|}{m_lg}
 +\frac{\|\boldsymbol\tau_l\|}{m_lg\vol(\object_l)^{1/3}}\right).
\end{equation*}
Here $l$ indexes objects in the resulting structure and $g$ is gravitational acceleration.
Candidates with $e(\action)\geq\epsilon_\mathrm{eq}$ are rejected after pose optimization, before simulation, so the equilibrium term ranks only admitted placements.
% epsilon_eq = 0.1 on both platforms (posegen_equilibrium_threshold; e = epsilon_eq is rejected).
% Reward/prior code also clips e at 1; inactive for admitted candidates since epsilon_eq < 1.
Let $q_l^{(j)}(t)$ denote object $l$'s pose during force trial $j$ (Sec.~\ref{sec:simulation}), starting from its nominal successor pose $q_l'$.
Disturbance sensitivity is
\begin{equation*}
 D=\min\!\left\{D_{\max},\max_{j,l,t}d_{\SE(3)}\bigl(q_l^{(j)}(t),q_l'\bigr)\right\},
\end{equation*}
where $d_{\SE(3)}$ sums Euclidean translation distance and angular distance weighted by $\lambda_\theta>0$.
The maximum spans force trials, all placed objects, and simulation time including recovery; $D_{\max}$ caps the penalty. Physical rejection criteria apply independently of the reward.

\subsection{Monte Carlo Tree Search}\label{sec:mcts}
We integrate these modules in batched, receding-horizon MCTS (Fig.~\ref{fig:overview}), following the parallel evaluation approach of~\cite{huang2022pmbs}.
Figure~\ref{fig:mcts_example} shows a recorded comparison with greedy placement.

\noindent \textbf{Batched Selection.}
For an optimized action $a=(i,q)$, let $\rho_\object^{\mathrm{pre}}$ denote the object-volume ratio evaluated at $q$, before simulation. Using the reward weights, the logit $\ell(a)=w_\object\rho_\object^{\mathrm{pre}}-w_E e(a)$ defines $P(\node_p,a)$ through a softmax over selectable children. Writing $N_{\node}=N(\node)$ and similarly for $Q_{\node}$ and $\hat N_{\node}$, an evaluated child $\node$ of $\node_p$ is selected using PUCT~\cite{silver2017mastering}:
\begin{equation}
    \puct(\node)=\frac{N_{\node}Q_{\node}}{N_{\node}+\hat N_{\node}}
    +cP(\node_p,a)\frac{\sqrt{N_{\node_p}+\hat N_{\node_p}}}
         {1+N_{\node}+\hat N_{\node}},
    \label{eq:puct}
\end{equation}
% tree_policy.selection_score requires positive effective parent visits;
% pending actions are handled before PUCT, so no max(..., 1) is used here.
where $c>0$ controls exploration, $\tmpvisit$ counts temporary reservations, and the first term is zero when its denominator is zero.
At non-root nodes, progressive widening~\cite{couetoux2011continuousuct} increases the number of candidate actions with completed visits.
Temporary reservations prevent duplicate evaluations within a batch without increasing the widening allowance.

\noindent \textbf{Parallel Expansion and Evaluation.}
After batch selection, fresh proposals pass through $\initpose\to\poseopt\to\simul$. Independent candidates are processed in parallel; selection never descends through an action without an evaluated successor. Failed candidates are excluded from further selection.

\noindent \textbf{Leaf Value Estimation and Backpropagation.}
We replace rollouts with a heuristic estimate of future rewards:
\begin{equation*}
 \hat V(\node)=
 \begin{cases}
  0, & \text{if failed or terminal},\\
  \hat{r}\sum_{j=0}^{\depth_{\node}-1}\gamma^j, & \text{otherwise},
 \end{cases}
\end{equation*}
where $\hat{r}$ is a prescribed per-step reward estimate and $\depth_{\node}$ the bootstrap horizon, capped by remaining depth and inventory (zero at the depth limit).
Backup starts from $r_{\node}+\gamma\hat V(\node)$, where $r_{\node}$ is the incoming action's reward, and recursively adds ancestor rewards with discount $\gamma$, updating $Q$, $N$, and clearing temporary reservations.
% \depth_{\node} = min(configured bootstrap horizon, remaining depth, remaining inventory).
% The native bootstrap excludes r_{\node} and its first-edge discount, as above.
% The failure override in backup is equivalent to r_{\node}=-1 and Vhat(\node)=0.
% Failure passes -1 to ancestors; the unselectable failed node itself records zero.
% Exhausted shallower nonterminal leaves are not repeatedly backed up.

\noindent \textbf{Action Selection and Tree Reuse.}
For each feasible root action $a$, let $G(a)$ be the maximum discounted observed return among its deepest evaluated feasible paths within the search horizon, including $a$'s reward and excluding bootstrap values.
Root-only paths are eligible. We select the action maximizing
\begin{equation*}
  J(a)=(1-\beta)Q(\node_a)+\beta G(a),\qquad \beta\in[0,1].
\end{equation*}
The path-return term counterbalances failures accumulated during exploration, which can depress the mean even when a promising feasible path exists.
If no root action is feasible, we return no placement.

After execution, we advance the root to the observed successor.
Evaluated descendants are retained when this state and the planning context match those used to construct the subtree; otherwise, the affected subtree and its statistics are discarded.
