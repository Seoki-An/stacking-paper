\section{Sequence Planning} \label{sec:sequence_planning}

In this section, we introduce the initial pose sampler $\initpose$ that generates initial poses for the pose optimization module $\poseopt$, the structural simulation module $\simul$ that evaluates the stability of the scene, and the Monte Carlo Tree Search (MCTS) module $\mcts$ for sequence planning.

\subsection{Initial Pose Sampling}
The initial pose sampler $\initpose(i_{k+1},\hat{q}_{k+1}\mid \state_k)$ generates candidate poses and corresponding object indices $i\in\inventory_k$ from the current state $\state_k = (\scene_k, \inventory_k, \target)$ and the candidate pose $\hat{q}_{k+1}$ is refined by the pose optimization module $\poseopt$.
The sampler is formulated as the following product of two distributions:
\begin{equation*}
    \begin{split}
        \initpose(i_{k+1},\hat{q}_{k+1}\mid \state_k) ={}& \pi_{xy}(\planar\mid i_{k+1},R,s_k) \\
        &\times \pi_\text{unif}(i_{k+1},R\mid s_k)        
    \end{split}
\end{equation*}
where $\pi_\text{unif}(i_{k+1},R\mid s_k)$ is a uniform distribution over $\inventory_k$ and a pre-defined finite rotation set $\mathcal{R}$, and $\pi_{xy}(\planar\mid i_{k+1},R,s_k)$ is a distribution over planar translations $\planar=(x,y)$ given the object $i_{k+1}$ and its orientation $R$.
The height $z$ of the candidate pose $\hat{q}_{k+1}=(R,t)$ is heuristically determined by the scene's upper-surface so that the object is placed above the scene since the pose optimization module $\poseopt$ will refine the candidate pose to find a stable placement pose $q_{k+1}$ that is in contact with the scene.
We will omit the dependency of $\pi_{xy}$ on $s_k$ in the following subsections for convenience.

For the planar translation distribution $\pi_{xy}(\planar\mid i_{k+1},R,s_k)$, we define a proposal score $\score(\planar\mid i_{k+1},R,s_k)$ that approximately estimates the quality of the candidate pose $\hat{q}_{k+1}$ based on the geometric information of the scene $\scene_k$, the target shape $\target$, and the object $i_{k+1}$.
Then, we define 
\begin{equation*}
    \pi_{xy}(\planar\mid i_{k+1},R,s_k) \propto \exp\left(\score(\planar\mid i_{k+1},R,s_k) / \tau\right)
\end{equation*}
so that the sampler favors candidate poses with higher proposal scores where $\tau > 0$ is a temperature parameter.
The proposal score $\score(\planar\mid i_{k+1},R,s_k)$ is formulated as a weighted sum of several geometric features that are computed based on the scene $\scene_k$, the target shape $\target$, and the object $i_{k+1}$:
\begin{equation*}
  \begin{split}
    \score(\planar\mid i_{k+1},R) ={}& w_\text{s}\score_\text{s}(\planar\mid i_{k+1},R)+w_\text{f}\score_\text{f}(\planar\mid i_{k+1},R) \\
    &+w_\text{b}\score_\text{b}(\planar\mid i_{k+1},R)-w_\text{h}\score_\text{h}(\planar\mid i_{k+1},R),
  \end{split}
%   \label{eq:initial_pose_score}
\end{equation*}
where $\score_\text{s}$ is the support area score map, $\score_\text{f}$ is the filled floor area score map, $\score_\text{b}$ is the boundary proximity score map, and $\score_\text{h}$ is the height score map, respectively with weight parameters $w_\text{h}$, $w_\text{s}$, $w_\text{f}, w_\text{b} > 0$.

Intuitively, the score $\score_\text{s}$ encourages the object to be placed on a larger support area, the score $\score_\text{f}$ encourages the object to fill the empty floor area, the score $\score_\text{b}$ encourages to fill the boundary of the target shape $\target$ first, and the last score $\score_\text{h}$ encourages the object to be placed at a lower height to improve stability.
The visualization examples of the score maps are shown in Fig. \ref{fig:score_map} and the details of the score map computation will be described in the appendix.

\begin{algorithm}[t]
  \caption{Initial pose sampling}
  \label{alg:initial_pose_sampling}
  \begin{algorithmic}[1]
    \Require State $\state_k=(\scene_k,\inventory_k,\target)$, rotation set $\mathcal{R}$, temperature $\tau$, score weights $\{w_\text{s},w_\text{f},w_\text{b},w_\text{h}\}$
    \State Sample $i_{k+1}\sim\operatorname{Unif}(\inventory_k)$ and $R\sim\operatorname{Unif}(\mathcal{R})$
    \State Construct the predefined planar sampling grid $\mathcal{G}$
    \ForAll{$\planar\in\mathcal{G}$}
      \State Compute $\score(\planar\mid i_{k+1},R)$ from the score maps
    \EndFor
    \State Sample $\planar=(x,y)\sim \pi_{xy}(\planar \mid i_{k+1},R, s_k)$
    \State Set $z$ from the upper-surface height of $\scene_k$
    \State \Return $i_{k+1}$ and $\hat{q}_{k+1}=(R,(x,y,z))$
  \end{algorithmic}
\end{algorithm}

\subsection{Simulation Module}

As mentioned in Sec. \ref{sec:overview}, after $\poseopt$ refines the candidate pose $\hat{q}_{k+1}$ to find a locally optimal placement pose $q_{k+1}$, the simulation module $\simul$ acts as a transition function $\state_{k+1} = \transition(\state_{k}, \action_{k})$ which simulates the physical behavior of the scene $\scene_{k+1}$ after placing the object $\object_{i_{k+1}}$ at the placement pose $q_{k+1}$.
The simulation module $\simul$ works in two steps: first, freezing the objects in the scene $\scene_k$ and simulate the newly placed object $\object_{i_{k+1}}$ to further refine the pose, and second, simulate the entire scene $\scene_{k+1}$ to ensure that the entire scene is stable.
For both steps, we use the early-termination condition to terminate the simulation if the scene is stable or expected to be unstable, and the simulation statistics are used to evaluate the reward of the action $\action_k$.
The early-termination condition is based on the mass-normalized kinetic energy $E_{\text{kin},i}$ and the accumulated energy $E_{\text{acc},i}$ of the object $\object_i$ in the scene $\scene_{k+1}$, which are defined as
\begin{align*}
    E_{\text{kin},i}(t) = \frac{1}{2m_i}V_i^\top M_i V_i, \quad 
    E_{\text{acc},i}(t) = \sum_{s=0}^{t} \sqrt{E_{\text{kin}(s),i}} \Delta t
\end{align*}
where $V_i \in \real^6$ is the linear and angular velocity of the object $\object_i$, $M_i \in \real^{6\times 6}$ is the mass matrix of the object $\object_i$, $m_i$ is the mass of the object $\object_i$, and $\Delta t$ is the simulation time step.
Then, the early-termination condition is defined as follows:
\begin{equation}
    \begin{split}
        &E_{\text{kin},i}(t) < \epsilon_\text{kin}\quad \text{for all } i \in \placed_{k+1} \text{ or } \\
        &E_{\text{acc},i}(t) > \epsilon_\text{acc}\quad \text{ for some } i \in \placed_{k+1}    
    \end{split}
    \label{eq:early_termination_condition}
\end{equation}
where $\epsilon_\text{kin}, \epsilon_\text{acc} > 0$ are the thresholds for the kinetic energy and the accumulated energy, respectively.

\subsection{Monte Carlo Tree Search for Sequence Planning}
Equipped with the modules $\initpose$, $\poseopt$, and $\simul$, we now use Monte Carlo Tree Search (MCTS) to explore the space of possible stacking sequences.
Given the root state $\state_0 = (\scene_0, \inventory_0, \target)$, MCTS iteratively builds a search tree $\tree$ where each node corresponds to a state $\state_k$ and each edge corresponds to an action $\action_k$.
