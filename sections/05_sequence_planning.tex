\section{Sequence Planning} \label{sec:sequence_planning}

\subsection{Initial Pose Sampling}
The initial pose sampler generates a set of candidates poses and the corresponding object indices in the inventory based on the target shape and the current scene configuration.
Initially, using the heightmap $H_\target:\real^2 \to \real$ of the target shape, the heightmap $H_\scene:\real^2 \to \real$ of the current scene configuration and the  the sampler construct a planar score map that indicates the potential placement locations for each object in the inventory.
